# Polymarket Paper Market Maker

An AI-assisted Python prototype for studying prediction-market market making using public data and a paper-only execution simulator. It includes order-book replay, inventory-aware quotes, simulated queue-based fills, and performance reports. It does not submit live orders.

Download and extract `polymarket-public.zip` to access the source, setup instructions, synthetic example session, tests, and documentation. The project README and `docs/` directory are inside the archive under `polymarket-paper-market-maker/`.

The offline suite passed 17 tests, lint, formatting, and type checks on November 10, 2026. Live data collection, Docker, remote CI, and PostgreSQL integration have not been verified. Results from the included session are synthetic and do not establish trading performance.
